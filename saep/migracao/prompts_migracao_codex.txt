PROMPTS MIGRACAO CODEX
Guia de prompts para reconstruir o sistema "Quiz Caca ao Tesouro" em outra stack
Objetivo: usar o Codex em sessoes futuras para recriar o projeto do zero com contexto consistente

1. COMO USAR ESTE ARQUIVO

Este arquivo organiza a migracao em prompts reutilizaveis.

Recomendacao de uso:
- usar uma sessao nova do Codex para cada fase grande
- sempre comecar pelo Prompt 1
- depois seguir a ordem sugerida
- quando uma fase ficar grande demais, quebrar em subtarefas

Regra importante:
- nao pedir "migre tudo" de uma vez
- sempre pedir leitura da documentacao e depois execucao incremental

2. ARQUIVOS QUE DEVEM SER TRATADOS COMO FONTE DE VERDADE

Em toda sessao de migracao, o Codex deve usar estes arquivos como base:

20. OBSERVACOES FINAIS

O melhor uso do Codex na migracao nao e um prompt gigante pedindo o projeto inteiro.

O melhor uso e:
- primeiro dar contexto
- depois trabalhar por fase
- sempre referenciar os arquivos .txt
- sempre limitar o escopo
- sempre revisar o que ja existe antes de expandir

Se a migracao for grande, repita esta rotina:
1. leitura e entendimento
2. implementacao pequena
3. validacao
4. proxima etapa

Fim do arquivo.
